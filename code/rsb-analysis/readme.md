Run `python3 parse-entries.py`. The shown graph represent the frequency of the used rsb entry in correspondence with the n-th (x-axis) `ret` instruction called. The sizes of the dots represent the frequencies, but are not for scale.

This implementation used as a reference [this article](https://comsec.ethz.ch/wp-content/files/ibpb_sp25.pdf) (section 6) without considering the alternate predictor.
